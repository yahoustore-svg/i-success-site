# I-SUCCESS — Site vitrine

Site statique du cabinet **I-SUCCESS**, cabinet d'orientation et d'accompagnement aux études à l'étranger basé à Niamey (Niger).

## Contenu

- `index.html` — accueil
- `offres.html` — packs et tarifs
- `destinations/` — Turquie, France, Maroc, Canada, Tunisie, Sénégal
- `temoignages.html`, `blog.html`, `article.html`, `about.html`, `contact.html`
- `css/styles.css`, `js/main.js`

## Lancer en local

```bash
python -m http.server 8123
# puis ouvrir http://localhost:8123/index.html
```

## Déploiement

Site 100% statique : déployable tel quel sur Netlify, Vercel ou GitHub Pages.
